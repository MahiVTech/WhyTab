# WhyTab
“I built a Chrome extension that captures user intent behind tabs, adds reminder-based task handling, and provides behavioral insights using local AI logic.”
# WhyTab 🧠⏰

WhyTab is a smart Chrome extension that helps you remember **why** you opened a tab — and reminds you **when it matters**.

Most people open 20+ tabs and forget their intent. WhyTab fixes that.

---

## 🚀 Features

- 🤔 Ask “Why did you open this tab?”
- ⏰ Smart reminders (30 min, custom time, edit anytime)
- 🧠 AI-based tab intent summaries
- 📜 Full tab history with insights
- 📊 Usage insights (day vs night, reasons)
- 🌙 Light / Dark mode
- 📤 Weekly report export
- ⚙️ Settings to control AI & theme

---

## 🛠️ Tech Stack

- JavaScript
- Chrome Extensions API (Manifest V3)
- Chrome Storage, Alarms & Notifications
